# PM12 precision mechanism factory

PM12 exercised MechAgent Bridge RC1 in an isolated Mechanomania 1.1.13.1 save on Minecraft 1.21.1, NeoForge 21.1.248 and Create 6.0.10. The factory was placed in creative mode as an empty structure. Its fixed water, lava and bamboo roots supported material generation. One Create creative motor powered the factory. The measured window began with empty monitored production inventories and ran without external material input, recipe changes or motor adjustments.

| Observation | Result |
| --- | --- |
| Sampling | 344 observations at roughly 15-second intervals |
| Elapsed wall time | 86 minutes and 0.013 seconds |
| Game ticks | 103,201, or approximately 20.00 TPS |
| Output | The designated output vault increased from 0 to 65 precision mechanisms |
| Continuation | Item 64 was first observed at about 84 minutes 45 seconds. Item 65 followed about 75 seconds later |
| Rate | 0.756 items per minute, below the 1 item/minute design target |

Inventory was summed from `create:precision_mechanism` item stacks in the output vault. Arrival time is bounded by adjacent observations. A later save read showed 85 cumulative items. It corroborates continued production after the formal window, with no timing claim for that interval. The measured output is an inventory observation for this setup. Factory Meter has a separate, narrower depot-to-hopper boundary.

The Bridge observed the network, machine state and output. Create supplied production and logistics. This case illustrates the accepted RC1 runtime behavior that v1.0.0 carries forward. The published summary omits world saves, pack files, player identifiers and raw local logs.
