# MechAgent Bridge v1.0.0

The first GitHub release supports Minecraft 1.21.1, NeoForge 21.1.248 and Create 6.0.10 on Java 21. Install the NeoForge JAR in your profile's `mods/` folder. Extract the MCP server ZIP, run `npm ci --omit=dev --ignore-scripts` with Node.js 22.16 or newer, and configure your MCP client to run `node /absolute/path/to/dist/index.js`. Start with the read token and `world,readonly`. [Installation and client examples](https://github.com/Rxwkovo/mcBridge/blob/v1.0.0/README.md)

The release carries forward scoped construction, loaded-world inspection, Create network and Contraption observation, telemetry history and the verified depot-to-hopper Factory Meter. Since RC1, the package versions and NeoForge metadata now match the stable tag, the public setup guide reflects the supported platform, and GitHub-only automation builds, tests and checks the assets before publication.

PM12 exercised the RC1 runtime in full Mechanomania. A single creative motor drove the factory from empty production inventories to 65 precision mechanisms in 86 minutes at about 20 TPS. It continued producing after item 64. Its observed 0.756 items/minute was below the 1 item/minute design target. [Case notes](https://github.com/Rxwkovo/mcBridge/blob/v1.0.0/docs/PM12.md)

Create network totals may be cached. Contraption observation covers loaded structures and has live verification for a minecart, a mechanical bearing and a mechanical piston. Elevators and trains remain unverified. Meter coverage may be partial across restarts and cannot guarantee exactly-once recovery. The release assets include SHA-256 checksums and retain the upstream MIT notice.
